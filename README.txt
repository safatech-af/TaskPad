TaskPad website for Safa Devs

1. Create a PUBLIC repository named taskpad under GitHub user safatech-af.
2. Upload index.html and privacy.html to the repository root.
3. GitHub repository Settings > Pages > Deploy from a branch > main > /(root).
4. Check these public links after deployment:
   https://safatech-af.github.io/taskpad/
   https://safatech-af.github.io/taskpad/privacy.html
